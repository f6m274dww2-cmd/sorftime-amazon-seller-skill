# 关键词 4 分类体系定义和打标规则

## 分类定义

| 分类 | 定义 | 识别特征 | 典型示例 |
|------|------|----------|----------|
| **核心词** | 高搜索量品类主词 | 短词（1-2 词）、月搜索量 >10000、品类通用名 | "power bank", "blender", "dog leash" |
| **长尾词** | 多词组合、精准描述产品属性 | 3 词以上、含属性/规格/品牌兼容词 | "10000mAh portable charger fast charging", "BPA-free personal blender" |
| **场景词** | 适用场景/人群/场合 | 含 "for [scene]" / "for [人群]" / 场景描述 | "power bank for iphone", "blender for smoothies", "dog leash for large dogs" |
| **痛点词** | 解决问题/缺陷/特殊需求 | 含功能优势词、否定前缀、问题解决词 | "leak-proof water bottle", "non-slip dog leash", "easy-clean blender" |

## 打标规则（LLM 离线分类）

### 判定优先级

当一个关键词同时符合多个分类特征时，按以下优先级判定：

1. **痛点词** > 场景词 > 长尾词 > 核心词
2. 含明确痛点解决词（leak-proof, non-slip, easy-clean, no-spill, durable 等）→ 优先归痛点词
3. 含明确场景/人群词（for, travel, office, kids, dogs 等）→ 归场景词
4. 3 词以上但无明确场景/痛点 → 归长尾词
5. 1-2 词 + 高搜索量 → 归核心词

### 关键词打标提示词模板

```
你是关键词分类 Agent。

【输入】
- 关键词列表（含月搜索量数据）

【任务】
按 4 分类规则打标：
1. 核心词：高搜索量品类主词（短词 1-2 词、月搜索量 >10000）
2. 长尾词：多词组合、精准（3 词以上、含属性词）
3. 场景词：适用场景/人群（含 "for [scene]" / "for [人群]"）
4. 痛点词：解决问题/缺陷（含 "leak-proof" / "non-slip" / "easy-xxx" 等）

判定优先级：痛点词 > 场景词 > 长尾词 > 核心词

【输出】
按 4 分类输出，每类关键词附带搜索量和 CPC 数据
```

## 词数目标与补全策略

### 目标

每个分类 **≥ 200 词**。

### 补全策略

当某分类不足 200 词时：

1. **优先**：扩大竞品 ASIN 反查范围（增加翻页 page 上限）
2. **备选**：增加新的竞品 ASIN 继续反查
3. **补充**：用 KeywordExtends 从种子词继续拓展
4. **仍不足**：在报告中标注「<分类> 词数不足，仅 N 词」

### 采集来源

| 来源 | 方法 | 预计词量 |
|------|------|----------|
| 竞品 ASIN 流量词反查 | 10 个竞品 × 30 页 × 20 词/页 | 最多 6000 词 |
| 关键词拓展 | KeywordExtends | 每次 100-200 词 |
| 类目反查 | CategoryRequestKeyword | 每次 100-200 词 |
| ABA 热门词查询 | KeywordQuery | 每次 20-200 词 |

## 选词漏斗

每分类独立执行选词漏斗：

```
候选池（≥200 词）
  → Top 20 代表词（按月搜索量降序）
    → 竞争度评估（搜索量/CPC/前 3 页竞争结构）
      → 入选 Top 5
```

### 入选标准

- 搜索量适中（不过度竞争）
- CPC 可承受
- 与产品高度相关
- 竞争分散（Top 3 点击占比 < 40%）
- 供需比高（搜索量/竞品数 > 5）
