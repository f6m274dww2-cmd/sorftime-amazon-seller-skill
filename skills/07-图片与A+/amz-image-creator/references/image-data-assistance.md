# 数据辅助生图方法论

## 核心原则

图片不是凭空设计的，而是由数据驱动的。用 Sorftime 数据回答三个问题：
1. **用户最关心什么卖点？** → 图片应该突出什么
2. **用户在什么场景使用？** → 场景图应该展示什么环境
3. **竞品图片怎么排的？** → 我们如何差异化

---

## 数据维度 → 图片内容映射

### 1. VOC（Customer Say）→ 卖点选择

**数据获取：** `product_customers_say`（MCP）/ `ProductCustomersSay`（CLI）

**分析方法：**
- 提取 Amazon 总结的客户声音文本
- 识别高频正面评价词 → 图片应突出的核心卖点
- 识别高频负面评价词 → 图片应展示"解决了这个问题"的对比

**映射规则：**
| VOC 信号 | 图片应用 |
|----------|----------|
| "easy to use" 高频 | 信息图展示 3 步使用流程 |
| "long battery life" 高频 | 主图/副图标注具体续航数据 |
| "leak proof" 高频 | 场景图展示倒置/倾倒不漏水 |
| "great for travel" 高频 | 生活方式图展示旅途中使用 |

### 2. 评论分析 → 痛点可视化

**数据获取：** `product_reviews`（MCP）/ `ProductReviewsQuery`（CLI），筛选 Negative 评论

**分析方法：**
- 提取差评中的 top complaints → 图片中展示"我们的产品没有这个问题"
- 提取好评中的 top use cases → 场景图展示这些使用场景

**映射规则：**
| 评论信号 | 图片应用 |
|----------|----------|
| 竞品差评："too bulky" | 我们的图展示紧凑尺寸对比 |
| 好评："perfect for camping" | 露营场景图 |
| 好评："kids love it" | 家庭/儿童场景图 |

### 3. 关键词数据 → 图片文字选择

**数据获取：** `keyword_detail` / `KeywordRequest`

**分析方法：**
- 取产品核心词的 Top 20 搜索词
- 高频词 → 图片上的文字标注（不超过 5-7 个词）
- 长尾场景词 → 场景图标题

**映射规则：**
| 关键词信号 | 图片应用 |
|------------|----------|
| "fast charging" 高搜索量 | 主图角标："Fast Charge" |
| "for iphone" 高搜索量 | 兼容性信息图 |
| "waterproof" 高搜索量 | 防水场景图 |

### 4. 竞品图片分析 → 差异化定位

**数据获取：** `keyword_search_results` / `KeywordSearchResults`（看 Top 10 竞品主图）

**分析方法：**
- 观察 Top 10 竞品的主图风格（白底/场景图/信息密度）
- 找出行业普遍缺失的图片类型 → 我们补上
- 找出行业普遍的构图套路 → 我们做差异化

**映射规则：**
| 竞品图片信号 | 差异化策略 |
|--------------|-----------|
| 全行业都是纯白底主图 | 我们加轻微渐变/光影提升质感 |
| 无人做尺寸对比图 | 我们加一张尺寸参考图（手持/参照物） |
| 竞品都是棚拍 | 我们加真实生活场景图 |

### 5. 用户画像 → 模特/风格选择

**数据获取：** `product_customers_say` + `product_reviews` 综合分析

**分析方法：**
- 从评论者描述中推断目标人群（年龄/性别/生活方式）
- 场景图/模特图选择匹配人群

### 6. Reddit 特征 → 社媒图风格

**数据获取：** `reddit_post_search`（raw call）

**分析方法：**
- 查看相关 Reddit 社区的热门帖子风格
- 提取社区偏好的视觉风格（搞笑/专业/极客风）
- 用于社媒推广图设计

## 图片类型规划

基于数据分析结果，规划一套完整的图片组合（通常 7 张）：

| 图位 | 类型 | 数据驱动要点 |
|------|------|-------------|
| Slot 1 | 主图（白底） | 产品核心角度，无文字，纯白背景 |
| Slot 2 | 核心卖点图 | VOC 提取的 #1 卖点 + 数据标注 |
| Slot 3 | 场景图 | 评论中高频使用场景 |
| Slot 4 | 对比图 | 竞品差评 vs 我们的优势 |
| Slot 5 | 信息图 | 解答 Q&A 常见问题 |
| Slot 6 | 尺寸/规格图 | 关键词中高频属性词 |
| Slot 7 | 信任/包装图 | 包装清单 + 售后保障 |

---

## 数据完整度检查

生成图片前确认：
- [ ] VOC 数据已获取（product_customers_say）
- [ ] 差评分析已完成（至少看了 10 条 Negative 评论）
- [ ] 关键词 Top 10 已获取
- [ ] 竞品图片风格已观察
- [ ] 每张图的卖点都有数据支撑（不是凭空想的）
