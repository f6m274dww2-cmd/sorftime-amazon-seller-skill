# 关键词分类到广告组的映射规则

## 核心映射表

| 词库分类 | 广告组归属 | 匹配方式 | 出价层级 | 预算占比 |
|----------|-----------|----------|----------|----------|
| 核心词 | Campaign: Core-Exact | Exact Match | 高 | 40-50% |
| 长尾词 | Campaign: LongTail-Phrase | Phrase Match | 中 | 20-25% |
| 场景词 | Campaign: Scenario-Exact | Exact Match | 中 | 15-20% |
| 痛点词 | Campaign: PainPoint-Exact | Exact Match | 中低 | 10-15% |
| （系统自动） | Campaign: Auto-Discovery | Auto | 低 | 10-15% |

---

## 各广告组详细配置

### Campaign: Auto-Discovery（自动广告）

| 配置项 | 值 |
|--------|-----|
| 广告类型 | SP Auto |
| 日预算 | 总预算的 10-15% |
| 默认出价 | CPC 区间下限 × 0.7 |
| 匹配类型 | Close Match + Loose Match + Substitutes + Complements |
| 目标 | 发现高转化搜索词 |
| 否定词 | 初期仅否定明显不相关词 |

**优化节奏**：每周查看搜索词报告，将高转化词移到手动广告组。

### Campaign: Core-Exact（核心词精准）

| 配置项 | 值 |
|--------|-----|
| 广告类型 | SP Manual |
| 日预算 | 总预算的 40-50% |
| 关键词 | 核心词 Top 10-20（按月搜索量降序） |
| 匹配方式 | Exact Match |
| 初始出价 | CPC 区间中值 × (1 + 采购后毛利率系数) |
| 目标 | 核心词排名卡位 |

**关键词选择标准**：
- 月搜索量 > 10000
- 与产品高度相关
- 竞争度中等或可控

### Campaign: LongTail-Phrase（长尾词词组）

| 配置项 | 值 |
|--------|-----|
| 广告类型 | SP Manual |
| 日预算 | 总预算的 20-25% |
| 关键词 | 长尾词 Top 20-30 |
| 匹配方式 | Phrase Match |
| 初始出价 | CPC 区间中值 × 0.8 |
| 目标 | 低成本捡漏精准流量 |

**关键词选择标准**：
- 3 词以上、含属性词
- 搜索量 500-5000
- 竞争度低（Top 3 点击占比 < 35%）

### Campaign: Scenario-Exact（场景词精准）

| 配置项 | 值 |
|--------|-----|
| 广告类型 | SP Manual |
| 日预算 | 总预算的 15-20% |
| 关键词 | 场景词 Top 15-20 |
| 匹配方式 | Exact Match |
| 初始出价 | CPC 区间中值 × 0.9 |
| 目标 | 抢占场景化流量 |

**关键词选择标准**：
- 含 "for [场景/人群]" 结构
- 与产品实际使用场景匹配
- 转化率预期较高（场景化搜索通常购买意图强）

### Campaign: PainPoint-Exact（痛点词精准）

| 配置项 | 值 |
|--------|-----|
| 广告类型 | SP Manual |
| 日预算 | 总预算的 10-15% |
| 关键词 | 痛点词 Top 10-15 |
| 匹配方式 | Exact Match |
| 初始出价 | CPC 区间中值 × 0.7 |
| 目标 | 精准命中解决问题需求 |

**关键词选择标准**：
- 产品确实解决该痛点
- 搜索量适中（1000-8000）
- 竞争度较低

---

## 否定词映射规则

| 词库分类 | 处理方式 |
|----------|----------|
| 与产品完全不相关的词 | 精确否定（Negative Exact） |
| 暗示低价/批发的词 | 词组否定（Negative Phrase）：cheap, wholesale, bulk, discount |
| 竞品品牌词 | 精确否定（除非做竞品定位 SD） |
| 季节性不匹配的词 | 精确否定（当前非旺季） |

## 预算分配示例

假设总日预算 $50：

| Campaign | 预算占比 | 日预算 | 出价范围 |
|----------|----------|--------|----------|
| Auto-Discovery | 15% | $7.5 | $0.35-0.50 |
| Core-Exact | 45% | $22.5 | $1.20-1.80 |
| LongTail-Phrase | 20% | $10.0 | $0.60-0.90 |
| Scenario-Exact | 12% | $6.0 | $0.80-1.20 |
| PainPoint-Exact | 8% | $4.0 | $0.50-0.80 |
| **合计** | **100%** | **$50.0** | — |

## 跨广告组去重原则

- 同一个关键词只在一个广告组投放（避免内部竞争）
- 核心词 → Core-Exact（Exact）
- 长尾词 → LongTail-Phrase（Phrase）
- 如果某长尾词表现极好 → 提升到 Core-Exact（Exact）
- 如果某核心词表现差 → 降到 LongTail-Phrase（Phrase）观察
