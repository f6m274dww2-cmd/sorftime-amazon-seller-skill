# 全链路交接合约

## 标准输入

- 站点、品类、目标用户、价格带、预算
- 售卖模式：FBA / FBM / 精品 / 铺货
- 当前阶段：发现 / 验证 / 采购 / 上架 / 放量 / 复盘
- 可接受风险：专利、合规、退货、库存、广告
- 是否允许高成本批量调用

## 候选漏斗

```text
任务机会
  → 20-50 个候选
  → ≥20 个可比较候选
  → Top 5-8 深挖
  → 专利/利润/供应链三闸门
  → Go / Caution / No-Go
```

不要用固定阈值自动删除边界候选。可以给风险徽章、排序和理由，但保留全量视图。

## Go / Caution / No-Go

| 结论 | 条件 |
|---|---|
| Go | 任务证据成立 + 类目可进 + 专利未发现高风险 + 利润达标 + 供应链可做 |
| Caution | 有明确机会，但专利不明、利润脆弱、季节窗口或供应链不稳 |
| No-Go | 核心需求不成立、专利高风险、无法达到最低毛利、供应不可控 |

## 证据字段

每条结论至少带：

- 工具名
- 站点
- ASIN / keyword / node_id / publication_no
- 采样时间
- 样本量
- 数据类型：观测 / 估算 / 推断
