# 市场分析框架与评分体系（amz-market-analysis）

> 融合 seller-agent methodology-cards（market-panorama / price-band-sweetspot / brand-gap-entry / variant-gap / cross-platform-gap）+ suite/references/category.md。

## 一、市场全景 11 维复合评分

类目值不值得进，不是单一指标说了算。11 维加权复合打分：

```
复合分 = w1市场规模 + w2增长趋势 + w3竞争强度 + w4价格天花板 + w5品牌集中度
       + w6季节性 + w7评论壁垒 + w8退货率 + w9物流适配 + w10广告成本 + w11合规风险
```

权重按卖家阶段调：新手加重 w3 竞争强度；专业加重 w10 广告成本。0-100 连续分，无硬截断。

**风险信号**：
- 负增长 + 高评论壁垒 = 衰退市场，不建议
- 品牌集中度 >50% + 评论壁垒 >1000 = 垄断市场，除非有颠覆性差异化否则不进
- 季节性分 >80 = 旺季驱动，新手易踩库存陷阱

## 二、价格带甜区

```
价格带机会指数 = 该带需求密度 ÷ 该带竞争密度
需求密度 ≈ 该带总销量 / 总搜索量；竞争密度 = 该带活跃 ASIN 数
```

- 分桶按 $5 或 $10，逐桶统计：ASIN 数、总销量、总销售额、平均评分、平均评论数
- 甜区特征：该带 ASIN 平均评论数明显低于邻带（新进入机会大）、品牌化程度适中、销量分布均匀
- **价格弹性悬崖**：某价位点（如 $19.99→$24.99 销量掉 40%）多由成本天花板（FBA 费阶、关税线）造成
- ⚠️ FBA 费阶陷阱：$19.99 刚触发更高费阶，实际利润可能低于 $17.99

## 三、品牌垄断脆弱性

```
垄断脆弱性 = 品牌集中度(35%) × 头部均评分(35%) × 价格溢价率(30%)
```

- Top3 份额 68% 和 72% 在集中度维度几乎同分——别因一个百分点判死刑
- 高集中 + 头部评分 <4.0 + 头部溢价 >类目均价 40% = 脆弱性高，"80% 价格买 95% 品质"的性价比切入可行
- 灰区陷阱：集中度 85%+ 但头部评分 4.6+ 且定价合理 = 品牌忠诚太强，勿正面硬刚
- 红旗：头部品牌近期密集上新 + 降价 = 正在防守，此时进场当炮灰
- 必须用 `keyword_search_results` 交叉验证：头部若已占满核心词前 3，攻击成本过高

## 四、变体缺口

```
变体缺口指数 = 父体销量 × Σ(各维度缺失覆盖率) × (1 / 该缺口位竞争者数)
```

- 高销量 ASIN 的局部小缺口（800 月销父体缺 1 个尺寸）> 低销量 ASIN 的全面缺口（50 月销缺 4 个尺寸）
- 缺口类型权重：尺寸 > 颜色 > 多件套装
- 关注覆盖率 <60% 的维度；表面缺口需用搜索量交叉验证（空可能是因为需求本就小）
- ⚠️ 变体 >20 个后库存管理复杂、评论稀释，不宜无限扩

## 五、类目竞争环境量化（Top100 上算）

| 指标 | 算法 | 含义 |
|---|---|---|
| HHI | Σ(各品牌销量份额²) | >2500 高度集中 |
| Top3/5/10/20 份额 | 头部销量占比 | 判断垄断程度 |
| 新品占比 | 上架 <90 天 ASIN 销量占比 | 新品能否挤进去 |
| 自营占比 | Amazon 自营销量占比 | 平台挤压风险 |
| 四象限 | 月销/价格/星级/评论数散点 | 找蓝海象限（高销量+低评论） |

## 六、趋势 6 维判生命周期

用 `CategoryTrend` 多维度看 12 个月：
- 销量（index 0）→ 体量增长/萎缩
- 均价（index 3）→ 价格带迁移/价格战
- 3 月新品份额（index 7）→ 新品成功率
- 自营占比（index 9）→ 平台垄断变化
- Top10 品牌垄断（index 34）→ 垄断加剧/分散
- 平均评论数（index 4）→ 类目成熟度

组合判断：增长 + 新品份额升 + 集中度降 = 上升期可进；衰退 + 集中度升 = 红海勿入。

## 七、进入建议产出模板

```
是否值得进入：GO / CAUTION / NO-GO（基于集中度 + 趋势 + 历史变化）
差异化机会：基于差评痛点 + 特征频率 + 蓝海词
投放策略：核心词 vs 蓝海词分层
风险提示：自营占比 + 头部集中度 + 价格带竞争
```
