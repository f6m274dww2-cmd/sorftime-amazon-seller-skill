# 专利风险审查方法

## 检索策略

### 外观设计

1. 用白底主图 + `query_mode=1`
2. 若重点是图案/形状精确匹配，追加 `query_mode=2`
3. 目标站点优先；供应链国家作为补充
4. 对命中结果逐件看轮廓、比例、关键装饰、连接方式
5. 不能只按接口相似度下结论

### 发明/实用新型

1. 品类核心词
2. 功能 + 结构组合词
3. 竞品品牌/申请人
4. 已知公开号/申请号反查
5. 用 LOC/IPC/CPC/GBC 分类收窄

### 检索充分性

至少同时完成：

- 1 次外观图搜
- 1 次核心关键词检索
- 1 次目标站点法律状态过滤
- 对高相关命中做详情查询

如果任何一项缺失，结论必须是“数据不足”，不能写“未发现风险”。

## 人工比对维度

| 维度 | 看什么 |
|---|---|
| 轮廓 | 整体外形、比例、转角、开口 |
| 结构 | 层数、支撑、连接、固定方式 |
| 功能 | 专利权利要求是否覆盖关键功能 |
| 装饰 | 图案、颜色、纹理、边缘 |
| 市场 | 专利是否在目标销售国有法律效力 |
| 状态 | Active / Pending / Expired / Unconfirmed |
| 时间 | 公开日、申请日、预计到期日与商业计划 |

## 风险表达模板

- **观测**：`patent_search_from_keyword` 在 US、Active/Pending 范围内返回 N 件去重结果，其中 M 件与产品结构/外观相关。
- **推断**：下列 2 件为高相关候选，原因是轮廓和层间支撑结构接近；是否落入权利要求需律师进一步比对。
- **动作**：在取得权利要求对照意见前，暂停大货采购与广告放量；可先改款或换目标市场。

## 禁止写法

- “没有专利，可以放心卖”
- “相似度 80%，所以侵权”
- “专利已过期”但没有法律状态/日期证据
- “全球都查过了”但只查了一个站点
